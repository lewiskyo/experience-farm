## 这是什么

一个结构化的实战案例集。每一篇都是独立的故事，聚焦一个具体问题：

- 当时发生了什么
- 我踩了什么坑
- AI 或文档没告诉我的那部分是什么
- 我从中沉淀了什么经验
- 留下了什么可复用的资产

## 耕作原则

1. **不追热点，只耕熟地** —— 只写我亲自验证过的东西。
2. **宁短勿空** —— 一篇只说一个点，但把这个点说透。
3. **可生长** —— 每条经验末尾留有"待探索的问题"，供日后回来补充。
4. **不重复发明轮子** —— 如果已有优秀的现成资料，我会引用而非重写。
